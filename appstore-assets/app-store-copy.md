## 描述

CloudDreamMarkdown 是一款专注本地 Markdown 文档阅读与轻量编辑的 iOS 工具。你可以从文件 App 打开 .md 或 .markdown 文档，在手机上快速查看排版后的内容，搜索关键词，并在需要时进入编辑模式完成简单修改。

它适合记录整理、文档检查、草稿预览和移动端阅读。应用不要求登录账号，不绑定云服务，核心操作都围绕本地文件完成。

主要功能：
- 打开 .md 和 .markdown 文件
- Markdown 内容预览
- 当前文档关键词搜索
- 轻量文本编辑
- 保存或另存文档
- 支持浅色、深色和跟随系统外观
